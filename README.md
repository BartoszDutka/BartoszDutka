## About Me

I am an IT Infrastructure and Network Administrator with over three years of professional experience in the healthcare sector.

My work covers enterprise infrastructure, system administration, network management, virtualization, cybersecurity, backup and disaster recovery, and IT automation.

I combine hands-on infrastructure management with software development to build practical tools that improve operational efficiency, system reliability, and security.
